# Diseño implementado

Cinco destinos persistentes: Hoy, Entrenar, Comidas, Progreso y Ajustes. Tema oscuro inicial de Material 3, fondos carbón, superficies diferenciadas, acento verde y controles táctiles amplios. La pantalla usa insets del sistema y desplazamiento vertical para teléfonos pequeños y escalas de fuente mayores.

Hoy prioriza la siguiente sesión y muestra consumo real separado del plan. Entrenar guarda acciones explícitas y conserva la sesión; Comidas permite seleccionar fecha, consultar ingredientes, registrar y modificar. Progreso diferencia ausencia de datos; Ajustes concentra permisos, preferencias y copias.

Los estados desconocidos muestran Sin datos, los errores se comunican en la interfaz y las acciones destructivas de importación explican el reemplazo. El abandono tiene diez confirmaciones con retorno y emergencia accesible. No se muestran límites de duración ni se presenta un permiso local como prueba de conexión con un reloj.
