# Technical decisions

Package filenames did not match contents. Reconstructed canonical paths from content without changing the original package. Standalone checkout in project/ preserves the unrelated parent repository.

## Toolchain and architecture

Verified official AGP 9.1.1 compatibility: Gradle 9.3.1, Build Tools 36.0.0, minimum JDK17. Local build and CI use JDK21; compile/targetSdk36 and minSdk28. Compose BOM2026.03.01 is a stable SDK36-compatible selection; the newer 2026.09.00 metadata requires SDK37, so it is not selected. Kotlin2.2.10 is AGP built-in; Compose and serialization compiler plugins match. KSP2.3.12 and Room2.8.4 use generated Kotlin implementations and export schema1.

One app module keeps domain, data, UI and platform packages separate. Room stores one versioned aggregate in a transaction: profile, preferences, snapshots and session state restore atomically. Preferences remain in Room instead of a separate DataStore to avoid a split transaction during restore. Platform SharedPreferences hold service transport state; the persisted Room session is authoritative for sensor baselines and logs. StateFlow drives Compose. Nutrition uses BigDecimal ingredient arithmetic and rounds at display. No backend, Internet permission, runtime AI, account, analytics or advertising.

The optional personal asset is generated by an explicit Gradle property in an ignored build directory with the property declared as a task input. Generic builds remove that asset. Separate application IDs allow local personal and generic installation side by side. Only the generic APK can be uploaded by CI.

Sources checked: [AGP9.1.1 compatibility](https://developer.android.com/build/releases/agp-9-1-0-release-notes), [Compose BOM mapping](https://developer.android.com/develop/ui/compose/bom/bom-mapping), [Kotlin Compose plugin](https://developer.android.com/jetpack/androidx/releases/compose-kotlin), [Room releases](https://developer.android.com/jetpack/androidx/releases/room), [Health Connect reads](https://developer.android.com/health-and-fitness/health-connect/read-data). SDK/vendor-specific physical outcomes remain separate from these documented API contracts.
